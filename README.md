A chess engine in under 4 KB of Python: a 10x12 mailbox board with make/unmake and Zobrist hashing, PVS alpha-beta with a transposition table, null-move pruning, late-move reductions, check extensions, killers and history, and a capture quiescence search, stopped by a fixed node budget so every move is deterministic.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
